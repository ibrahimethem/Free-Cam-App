Code signing policy

What is signed, who approves it, and the current status of our releases.

Current status

The public macOS package uses the developer's Apple Developer ID signature and Apple notarization. Windows test packages are currently unsigned. The initial application to the SignPath Foundation was declined because the project needs an established usage and reputation history. No Foundation sponsorship or certificate is claimed.

Alternative Windows distribution options are being evaluated. A Microsoft Store package has not been released. Any future unsigned public beta will be explicitly labeled unsigned; it will not be presented as a signed production release. Do not disable Windows security features or install an untrusted root certificate to run NoSub.

Maintainer and approval roles

Committer, reviewer and signing approver: İbrahim Ethem Karalı (@ibrahimethem). Production signing requires the maintainer's manual approval. External contributions must be reviewed before entering a release build. Multi-factor authentication is required for repository and signing-service access.

Build origin and signing scope

Windows signing requests must originate from the reviewed source in the public repository, built on GitHub-hosted runners. Pull requests and unreviewed branches must not receive production signing credentials.

Project executables, camera components and installers are distinct signing targets. The camera DLL includes modified Microsoft sample code and requires explicit eligibility review. Upstream Python, Qt and other third-party binaries must not be re-signed as original NoSub code.

Release checks

A release is not marked signed until its signatures and timestamps verify against the intended publisher. Installers must cover the embedded application, camera components, uninstaller and outer installer. Checksums are generated after signing. Failed or incomplete signing blocks production publication.

License and privacy

Original project code is MIT licensed; third-party components retain their own licenses. NoSub sends camera data only to the receiver selected by the user, with no advertising or analytics SDK. See the Privacy Policy and support contact.
