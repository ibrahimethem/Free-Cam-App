Install. Pair. Stream.

1. Install the receiver

On Mac, quit the old app before replacing it in Applications. On Windows, quit from the notification area before running the installer.

2. Connect your iPhone

Install NoSub Cam, allow Camera and Local Network access, then scan the pairing QR code in NoSub Studio. Use a trusted local network or Direct USB.

3. Enable webcam output

Approve the camera extension on Mac or install the Windows camera component. Enable output and select NoSub Camera in your video app. OBS is optional.
